# Proposal

## Why

Two independent post-Wave-6 audits of `master_v2` (`b2a5ce3`) — the SDD/architecture `/deep-audit` (`63` verified findings: `17` High, `36` Medium, `10` Low) and multi-engine VVAH scans (`oQ4e-mtp` `126` findings across `72` unique groups plus `claude-cli` `Opus 4.7` high-precision scan) — exposed orthogonal gaps in DNS-rebinding SSRF validation, unbounded `response.read()` memory buffering, TLS trust-store and SQLite at-rest file permissions, `WriteSession` `System Data` routing, fail-closed `SessionCleaner` cache hygiene, multi-scope cache invalidation, atomic incremental `smart-fast` sync, boundary SID redaction, MCP live-quota/CPCRUD isolation, and governance doc alignment.

Remediating all ~75 combined items in one monolithic PR would slow review and conflate foundational security/cache invariants with higher-level policy engines. Consistent with prior Waves 3–6, Wave 7 hardens the foundational **Transport, TLS, Sessions, Storage, Cache/Sync, Script SID-Redaction, MCP Server, API Reference, and Governance** layers (`27` `DA-*` findings + `13` `VVAH` security/hardening groups), while explicitly staging **Wave 8** (`27` `DA-*` + `VVAH` policy-layer items including rulebase completeness checks and `is_cleanup_rule` traffic gating across CPCRUD, Change Reports, Rulebase, Gateway Topology, and Replay Emulator) and **Wave 9** (`9` `DA-*` Monolith Refactoring findings) as follow-up changes.

## What Changes

- **Transport, Explicit IP Pinning, TLS Trust Store & SQLite At-Rest Hardening**:
  - **DNS Rebinding / SSRF Fix** (`DA-001`): Use `.issubset()` across all resolved DNS answers in `validate_explicit_server_ip` (`src/arodonata/adapters/checkpoint/target_resolver.py`) and return/connect to the validated canonical IP instead of letting `aiohttp` re-resolve an unpinned hostname.
  - **Pre-Login Command Validation, Bounded Response Bodies, Pool Canonicalization & Config** (`DA-041`, `DA-054`, `DA-061`, `VVAH-CLAUDE-01`): Validate commands via `validate_command_name()` at `AMgmtClient.api_call` entry before `is_readonly_command()` or login network I/O; bound HTTP response body ingestion in `ApiTransport` using `ArodonataSettings.max_response_bytes` (`>= 1024`, default `64 MiB`) to prevent OOM (`CWE-770`); canonicalize host keys in `VerifiedConnectionPool`; add explicit `1..65535` TCP port bounds to `ArodonataSettings.mgmt_port`.
  - **TLS Trust Store & Local SQLite Cache Permissions** (`VVAH-TLS-01`, `VVAH-DB-01`, `VVAH-CLAUDE-05`): Create `tls_known_hosts.json` parent directories with mode `0o700`, reject symlinked trust-store files (`S_ISLNK`) and unsafe non-sticky parent directory group/world write bits before reads or writes (preserving `uid=0` read-only `0444`/`0644` container `ConfigMap` mounts while warning on `euid`-owned `tofu` stores with group/world read bits), enforce `0o700` parent directories + `0o600` file permissions on newly created local file-backed SQLite cache databases holding `arodonata_sid_cache`, and preserve `SCN-TRANS-002-2` known-MDS cross-IP trust by design.
- **Session Routing, Fail-Closed SessionCleaner & Concurrency Safety**:
  - **System Data Isolation from WriteSession** (`DA-003`): Match active `WriteSession` via `normalize_domain_key()` in `AMgmtClient.api_call`, `ClientLifecycleMixin.api_call`, and `_mutate_object` so `domain=None` (`System Data`) calls never route into a domain-scoped `WriteSession`.
  - **Fail-Closed Startup Cleanup** (`DA-042` — fail-closed resolution): Close `SessionCleaner`'s read-write cleanup session via `logout_sid` after discarding stale sessions instead of seeding an RW session into `arodonata_sid_cache` (enforcing `REQ-SESS-003` over legacy `SCN-SESS-004-1`).
  - **Cancellation, Timeout Classification & Keepalive Freshness** (`DA-019`, `DA-021`, `DA-022`): Propagate `BaseException` (`asyncio.CancelledError`) in `LoginCoordinator.logout_sid`; classify `RateLimitTimeoutError` as `request_sent=False` without evicting healthy shared read-only SIDs; honor `keepalive_sid`-extended `expires_at` in `is_sid_entry_fresh` and normalize omitted `domain` during `keepalive_sid` eviction.
- **Timestamped Cache Invalidation, Atomic Incremental Sync & Search Isolation**:
  - **Persistent Multi-Scope Domain Invalidation** (`DA-002`): Replace single-shot set `.discard()` in `DomainSyncCoordinator` with monotonic/UTC `_invalidated_at` timestamps compared against each `(scope, item_type)` `synced_at`, support `DomainListRefreshTracker.invalidate(None)`, and ensure `WriteSession` publish invalidates domains even with an injected `AMgmtClient`.
  - **Atomic Synchronization** (`smart-fast`, `DA-004`): Pre-hydrate all modified UIDs via `show-object` before opening the database write transaction in `ObjectService` and `ServiceCacheService`, committing deletions, upserts, and `arodonata_domain_sync_state` atomically in a single transaction.
  - **On-Demand Lookup, Mask-0 Preservation & Overlay Isolation** (`DA-005`, `DA-023`, `DA-024`, `DA-025`, `DA-030`, `DA-031`, `VVAH-SEARCH-01`): Refresh non-default `obj_type` once on `find_object` without double-reloading in `force` mode; preserve `mask-length4 == 0` (`0.0.0.0/0`); isolate `WriteSession` overlay merges to matching `(mgmt_name, target_domains)` and `include_global`; normalize service aliases/casing consistently in `ServiceCacheService`; preserve multi-domain `Global` UID group memberships without overwrite; isolate cluster members by `(mgmt_name, domain_name)` and avoid non-group `CPObject` shadowing in `resolve_group_with_members`; clamp `limit`/`offset` and cap `group_by` result cardinality in `query_objects`.
- **End-to-End SID Redaction, MCP Quota/CPCRUD Hardening, API Reference & Governance Sync**:
  - **Boundary SID Redaction** (`DA-011`, `DA-037`, `VVAH-SID-01`, `VVAH-MCP-SID-01`): Scrub patterned and active/dedicated SIDs on `ScriptTargetExecutionResult`, `RepositoryScriptExecutionOutcome`, `GatewayCliResult`, and all `ScriptRepositoryService.run_repository_script` exception paths (including active `WriteSession`); shield `logout_sid` and retain just-closed `dedicated_sid` on mutating MCP `api_call` errors; thread `known_sids` into `json_tool_result` across read and admin MCP tools.
  - **MCP Quota, Cache Mode, Domain Pre-Validation, Origin & CPCRUD Isolation** (`DA-016`, `DA-044`, `DA-045`, `VVAH-MCP-QUOTA-01`, `VVAH-MCP-CPCRUD-01`, `VVAH-MCP-ORIGIN-01`, `VVAH-MCP-TRUST-DOC`): Check live quota and cold-cache upgrades across all touched scopes (`objects`, `services`, `assets`) and composite-ID domains in `query_objects`, `show_object`, and `get_group_members`, and enforce proportional live-quota charges (or bounded fan-out) on multi-domain `cache_control(action="refresh")` / `change_report(scopes=...)`; honor `cache_mode="cache"` and MDS cache-only downgrades in `show_object`; resolve default `mgmt_name` when `domain`/`domains` is passed with `mgmt_name=None`; bind `plan_id` inside `_sign_plan` HMAC, block cross-caller `plan_id` re-keying in `plan_store`, and evict same-caller staged sessions before cross-caller LRU eviction; reject present-but-blank `Origin` headers; document the service-account / server-scoped visibility trust boundary in `mcp-server`.
  - **API Reference & Governance Docs** (`DA-055`, `VVAH-APIREF-01`, `DA-057`, `DA-058`, `DA-059`, `DA-060`): Validate `valid_values` on `list[enum]` fields and cap deduplicated `describe_command` batch lists (`<= 50`); align `SSEEvent.encode()` in `client-and-facade` spec, `arodonata_distributed_locks` in `AGENTS.md` and `openspec/config.yaml`, and `17` SQL tables in `README.md`.

## Capabilities

### New Capabilities

- None (`arodonata` reuses existing capabilities).

### Modified Capabilities

- `transport-and-tls`: Pre-login command name validation, `tls_known_hosts.json` directory/symlink security checks and read-bit warning, canonical connection pool keys, bounded response-body reads, and `RateLimitTimeoutError` `request_sent=False` classification (`REQ-TRANS-001`, `REQ-TRANS-003`, `REQ-TRANS-004`, `REQ-TRANS-007`).
- `sessions-and-mdm`: Normalized `System Data` routing away from domain `WriteSession`, keepalive TTL freshness and normalized domain eviction, fail-closed `SessionCleaner` logout without RW cache seeding, `CancelledError` propagation in `logout_sid`, and `.issubset()` + pinned canonical IP SSRF validation (`REQ-SESS-002`, `REQ-SESS-003`, `REQ-SESS-004`, `REQ-SESS-007`, `REQ-SESS-008`).
- `cache-and-sync`: Local SQLite cache `0700`/`0600` permissions, timestamped multi-scope domain invalidation, atomic post-hydration `smart-fast` commits, on-demand `obj_type` sync, service alias normalization, `0.0.0.0/0` mask preservation, overlay isolation, and multi-domain `Global` + cluster group resolution (`REQ-CACHE-001`, `REQ-CACHE-004`, `REQ-CACHE-005`, `REQ-CACHE-006`, `REQ-CACHE-007`, `REQ-CACHE-013`, `REQ-CACHE-014`).
- `client-and-facade`: Overlay scoping in typed getters, injected-client `WriteSession` invalidation, on-demand `find_object` single-reload semantics, `run_repository_script` exception SID scrubbing, and `SSEEvent.encode()` spec alignment (`REQ-CLIENT-003`, `REQ-CLIENT-005`, `REQ-CLIENT-012`, `REQ-CLIENT-016`).
- `configuration`: Explicit `1..65535` bounds enforcement on `ArodonataSettings.mgmt_port` and bounded `max_response_bytes` (`REQ-CONFIG-009`).
- `mcp-server`: Blank `Origin` rejection and trust-model documentation, `show_object` `cache`-only fidelity, `query_objects` bounds, `plan_id` HMAC binding and per-caller staged-session eviction, multi-scope/composite live quota accounting, default `mgmt_name` domain validation, and complete `known_sids` error/output redaction (`REQ-MCP-001`, `REQ-MCP-002`, `REQ-MCP-004`, `REQ-MCP-009`, `REQ-MCP-010`, `REQ-MCP-012`).
- `gateway-topology`: Boundary SID scrubbing on CLI/script result models and non-dedicated `ScriptRepositoryService` failure paths (`REQ-TOPO-020`).
- `api-reference`: Bounded deduplicated `describe_command` batch inputs and `list[enum]` `valid_values` validation (`REQ-APIREF-003`, `REQ-APIREF-004`).

## Impact

- **Source Modules**: `src/arodonata/adapters/checkpoint/` (`target_resolver.py`, `tls.py`, `transport.py`, `client.py`, `sessions.py`, `session_credentials.py`, `session_cleaner.py`), `src/arodonata/adapters/storage/database.py`, `src/arodonata/core/config.py`, `src/arodonata/core/models/objects.py`, `src/arodonata/core/services/` (`sync_coordinator.py`, `domain_service.py`, `lifecycle.py`, `object_service.py`, `service_cache.py`, `search_service.py`, `script_service.py`), `src/arodonata/api_reference/engine.py`, `src/arodonata/mcp/` (`security.py`, `errors.py`, `tools/*.py`, `cpcrud.py`).
- **Governance & Root Docs**: `AGENTS.md`, `openspec/config.yaml`, `README.md`, `CHANGELOG.md`.
- **Tests**: New and updated `@pytest.mark.spec(...)` unit tests across transport, session, storage, cache, search, script, API reference, and MCP test suites.
- **Public API Compatibility**: Preserves public SDK method signatures and MCP tool names; tightens security validation (`validate_explicit_server_ip` returns canonical pinned IP, `mgmt_port` rejects out-of-range ports, blank `Origin` rejected, `describe_command` batch `> 50` rejected, `SessionCleaner` no longer seeds RW SIDs into `arodonata_sid_cache`).
