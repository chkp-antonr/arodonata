# Design: Wave 7 Foundational Security, At-Rest Hygiene, Cache Integrity, and MCP Hardening

## Context

See [proposal.md](proposal.md) for audit provenance (`2611231222-deep-audit.json`, `VVAH oQ4e-mtp` `findings.json`, and `VVAH claude-cli` `findings.json`) and wave partitioning rationale. Architectural constraints from `openspec/config.yaml` and `AGENTS.md` apply unchanged: strict hexagonal port boundaries (`INV-1`), zero SID exposure at any logging/error/output boundary (`INV-2`), naive UTC timestamps in DB columns (`INV-3`), provider-agnostic OpenTelemetry (`INV-5`), and cross-worker SQLite/PostgreSQL concurrency safety.

## Goals / Non-Goals

- **Goals**:
  - Eliminate DNS-rebinding SSRF (`DA-001`), unbounded response-body memory reads (`VVAH-CLAUDE-01`), pre-login command validation gaps (`DA-041`), pool key casing/IPv6 mismatches (`DA-054`), unsafe trust-store / local SQLite DB permissions (`VVAH-TLS-01`, `VVAH-DB-01`, `VVAH-CLAUDE-05`), and unbounded `mgmt_port` / `max_response_bytes` config (`DA-061`).
  - Isolate `System Data` calls from domain-scoped `WriteSession` (`DA-003`), eliminate RW SID seeding in `SessionCleaner` (`DA-042` fail-closed), fix `logout_sid` cancellation propagation (`DA-019`), `RateLimitTimeoutError` `request_sent=False` semantics (`DA-021`), and keepalive freshness/domain normalization (`DA-022`).
  - Make multi-scope domain invalidation persistent per scope (`DA-002`), make `smart-fast` incremental syncs atomic across `show-object` hydration (`DA-004`), and fix `find_object` non-default `obj_type`, `0.0.0.0/0` mask-length preservation, `WriteSession` overlay isolation, service alias normalization, `Global` UID memberships, and domain-scoped cluster lookup (`DA-005`, `DA-023`, `DA-024`, `DA-025`, `DA-030`, `DA-031`, `VVAH-SEARCH-01`).
  - Close script/CLI/MCP SID redaction leaks (`DA-011`, `DA-037`, `VVAH-SID-01`, `VVAH-MCP-SID-01`), close MCP live-quota/cache-mode/domain-validation/CPCRUD-eviction/`plan_id`/Origin gaps (`DA-016`, `DA-044`, `DA-045`, `VVAH-MCP-*`), fix `ApiReferenceEngine` `list[enum]` validation and batch caps (`DA-055`, `VVAH-APIREF-01`), and align governance documentation (`DA-057`..`DA-060`).
- **Non-Goals**:
  - Remediating higher-level policy/rendering bugs in CPCRUD, Change Reports, Rulebase, Gateway Topology, or Replay Emulator (explicitly deferred to **Wave 8**) or monolithic decomposition (explicitly deferred to **Wave 9**).
  - Weakening `SCN-TRANS-002-2` known-MDS cross-IP TLS identity matching, which is an intentional Check Point MDS architectural requirement rather than a defect.

## Decisions

1. **Canonical IP Pinning & DNS Validation** (`.issubset()`, `DA-001`):
   - *Choice*: Change `validate_explicit_server_ip(...)` (`target_resolver.py`) to require `resolved_ips.issubset(trusted_ips)` (rejecting dual-A-record responses mixing one trusted IP with any untrusted IP like `169.254.169.254`), return the canonical validated IP string (e.g., sorted deterministic member of `resolved_ips`), and pass that pinned IP into `AMgmtClient` / `VerifiedConnectionPool` transport calls instead of the original hostname.
   - *Alternative Rejected*: Keeping boolean `.intersection()` validation with raw hostname forwarding to `aiohttp` — leaves a TOCTOU DNS rebinding window between validation and `socket.connect()`.
2. **WriteSession System Data Isolation & Fail-Closed SessionCleaner** (`DA-003`, `DA-042`):
   - *Choice*: Normalize both the target `domain` and `active_ws.domain_name` with `normalize_domain_key()` inside `AMgmtClient.api_call`, `ClientLifecycleMixin.api_call`, and `_mutate_object` so `domain=None` (`"System Data"`) never binds to a domain `WriteSession` (e.g., `"Corp"`). Simultaneously update `SessionCleaner` to always execute `logout_sid` on its temporary RW session (`finally`) and never write RW SIDs into `arodonata_sid_cache` (aligning `SCN-SESS-004-1` fail-closed with `REQ-SESS-003`).
   - *Alternative Rejected*: Seeding an RW probe SID into `arodonata_sid_cache` for startup convenience (`DA-042` status quo) — violates the core read-only SID pool invariant.
3. **Filesystem Mode Hardening & Bounded HTTP Reads** (`0700` / `0600`, `max_response_bytes`, `VVAH-TLS-01`, `VVAH-DB-01`, `VVAH-CLAUDE-01`, `VVAH-CLAUDE-05`):
   - *Choice*: Create `tls_known_hosts.json` parent directories with `mode=0o700`, reject symlinked trust-store or lock targets (`os.lstat` / `stat.S_ISLNK`), reject group/world-writable non-sticky parent directories before reads or writes (`TrustStoreError`), preserve compatibility with `uid=0` read-only `0444`/`0644` container `ConfigMap` mounts while logging a `WARNING` on `euid`-owned `tofu` stores with group/world read bits (`S_IRGRP | S_IROTH`), and apply `0o700` parent dirs + `0o600` file permissions on newly created local file-backed SQLite cache DBs. Enforce `ArodonataSettings.max_response_bytes` (`>= 1024`, default `64 MiB`) in `ApiTransport` by checking `Content-Length` and reading `response.content.read(limit + 1)`, raising `TransportError(phase="read", request_sent=True)` on overflow without retry.
   - *Alternative Rejected*: Rejecting all `0644` `tls_known_hosts.json` mounts hard (breaks Kubernetes/Docker `uid=0` `ConfigMap` mounts and read-only fixture tests) or buffering unbounded `await response.read()` payloads in memory (`CWE-770`).
4. **Timestamped Multi-Scope Domain Invalidation & Two-Phase Atomic Sync** (`smart-fast`, `DA-002`, `DA-004`):
   - *Choice*: Replace `DomainSyncCoordinator`'s destructively popped `_invalidated` set with `_invalidated_at: dict[tuple[str, str], float | datetime]` (supporting `domain="*"` wildcards and comparing against each `(scope, item_type)` row's `synced_at` timestamp), support `DomainListRefreshTracker.invalidate(None)`, and invoke coordinator invalidation from `ClientLifecycleMixin.write_session()` even when using an injected external `AMgmtClient`. In `ObjectService` and `ServiceCacheService` `"smart-fast"` paths, pre-hydrate all changed UIDs via `show-object` in memory BEFORE opening the DB write transaction, then commit deletions, `ON CONFLICT` upserts, and sync state atomically in one transaction.
   - *Alternative Rejected*: Clearing invalidation on first partial sync or deleting rows before remote `show-object` calls — both cause silent stale reads or half-empty caches on transient API errors.
5. **Search Overlay Isolation, Zero-Mask Preservation & Group/Cluster Disambiguation** (`0.0.0.0/0`, `DA-005`, `DA-023`..`DA-025`, `DA-030`, `DA-031`):
   - *Choice*: Explicitly check `is not None` for `mask-length4 == 0` (`CPObject.from_cp_dict`); normalize service type aliases/casing at both SQL and `SessionOverlay` boundaries (`ServiceCacheService`); filter `SessionOverlay` merges by `(mgmt_name, target_domains, include_global)` (`SearchService`, `ObjectService`); trigger single on-demand refresh in `find_object` when `obj_type` is outside default types (avoiding double `force` syncs); key `Global` group membership maps by `(domain_name, uid)` before projecting `SearchResult.memberships` so distinct domains sharing a `Global` UID do not overwrite one another; and restrict `ClusterMember` parent expansion by `(mgmt_name, domain_name)` while prioritizing true group/cluster entities over same-named host/network collisions.
6. **End-to-End Boundary SID Scrubbing** (`DA-011`, `DA-037`, `VVAH-SID-01`, `VVAH-MCP-SID-01`):
   - *Choice*: Apply unified SID redaction helpers (`redact_sid` + active/dedicated SIDs) inside Pydantic validators/builders for `ScriptTargetExecutionResult`, `RepositoryScriptExecutionOutcome`, and `GatewayCliResult`, wrap every exception branch of `ScriptRepositoryService.run_repository_script` (including active `WriteSession`), shield `logout_sid` and pass the just-closed `dedicated_sid` on error in MCP mutating `api_call`, and thread `known_sids` into `json_tool_result` across `objects.py`, `rulebase.py`, `admin.py`, `lookup.py`, and `topology.py`.
7. **MCP Multi-Scope Quota, Plan HMAC Binding & Per-Caller Staged Eviction** (`plan_id`, `DA-016`, `DA-044`, `DA-045`, `VVAH-MCP-*`):
   - *Choice*: Upgrade `query_objects`, `show_object`, and `get_group_members` to evaluate live-quota and cold-upgrade checks for every touched scope (`objects`, `services`, `assets`) and resolved composite-ID domain; enforce proportional `live` quota accounting or bounded domain fan-out in `cache_control(action="refresh")` and `change_report(scopes=...)`; honor `cache_mode="cache"` and MDS cache-only downgrades in `show_object`; resolve default `mgmt_name` whenever `domain`/`domains` is given; reject present-but-blank `Origin` headers; bind `plan_id` into `_sign_plan`'s HMAC canonical payload, reject overwriting another caller's `plan_id` in `plan_store`, and evict same-caller entries in `staged_session_store` before evicting another caller's entry.
   - *Alternative Rejected*: Global FIFO eviction in `staged_session_store` and unsigned `plan_id` keys — allows one caller to evict or overwrite another caller's server-side references.

## Risks / Trade-offs

- `[Strict explicit_server_ip .issubset() breaks misconfigured split-horizon DNS where one hostname resolves to both a trusted management IP and an untrusted external IP]` → Document as intentional SSRF protection (`SCN-SESS-008-1`); operators must list all valid standby/MDS IPs via `mgmt_servers` or discovery.
- `[Strict 0700/0600 filesystem checks reject existing shared group-writable trust stores]` → Matches existing `TrustStoreError` expectations in `REQ-TRANS-003` (`SCN-TRANS-003-3`), emitting explicit expected permissions in the error message.
- `[SessionCleaner no longer seeding arodonata_sid_cache adds one extra read-only login on the very first read call after startup]` → Negligible one-time startup cost compared to eliminating RW credentials from `arodonata_sid_cache` (`DA-042` fail-closed mandate).
