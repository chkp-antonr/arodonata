# Design

## Context

See `proposal.md` for motivation and scope across the 9 remaining Deep Audit findings (`DA-046`..`DA-053`, `DA-063`). All work runs on dedicated branch `refactor/wave-9-architecture-and-performance` and must respect existing repository architectural and compatibility invariants:

- **Hexagonal AST boundaries** (`tests/unit/test_architecture_boundaries.py`): `core` never imports `adapters`, `client`, `mcp`, `cpcrud`, `reports`, `rulebase`, `testing`, or concrete I/O drivers; `adapters` never imports `client`, `mcp`, `cpcrud`, `reports`, `rulebase`, or `testing`.
- **Module LOC limits** (`tests/unit/test_wave5_domain_engines.py`): every decomposed module listed in `refactored_files` (including `cpcrud/planner.py`, `cpcrud/executor.py`, `cpcrud/_state_reader_*.py`, `reports/_renderer_formatting.py`, `reports/_collector_diffs.py`) must remain `<= 700` LOC, and all new submodules must stay well under 700 LOC.
- **Backward-compatible symbol identity and telemetry**:
  - `arodonata.adapters.checkpoint.sessions.parse_domain_entry is arodonata.adapters.checkpoint.response_classifiers.parse_domain_entry` (`test_wave3_compat_and_fixes.py`).
  - `arodonata.core.services.search_service` continues exporting `SearchService`, `ClassifiedSearchTerm`, `classify_search_term`, `matches_classified_term`, and `SearchService._resolve_implicit_domain_mode` with identical `@traced` span names, `__module__`, `__qualname__`, and `arlogi` logger channels.

## Goals / Non-Goals

**Goals:**

- Eliminate quadratic per-rule and per-object CPU scans in `filter_numbered_rulebase` and `find_unused_objects` / `delete_unused_objects` without changing observable match or cascade-deletion results.
- Replace diverged duplicate code paths (report object summaries, object/service cache sync, domain entry parsing, MDS fallback, `WriteSession` lifecycle, CPCRUD state-reader lookups, staged finalizers, inverse helpers) with single canonical helpers.
- Split oversized monolithic modules and functions (`SearchService`, `VSXRelationshipManager`, `ScriptRepositoryService.run_repository_script`, `_collect_gateway_routes_impl`, `Planner.decide`, `compute_object_diff`, `compute_rule_diff`) into cohesive single-purpose units.

**Non-Goals:**

- No breaking changes to public method signatures, return models, SQLite/PostgreSQL schema tables, or Check Point wire formats.
- No speculative feature additions outside the 9 Deep Audit refactoring/performance findings.

## Decisions

1. **Optional precomputed index in `filter_numbered_rulebase` (`DA-046`)**: Build a frozen index dataclass (`_RulebaseFilterIndex`) containing pre-parsed query IP/CIDR tokens, `by_uid` / `by_name` / `reverse_parents` object and service group graphs, and precomputed per-token `(matching_obj_ids, matching_svc_ids)` sets once in `filter_numbered_rulebase`, passing it into `rule_matches_filter(..., _precomputed=...)`. Direct external callers of `rule_matches_filter` omit `_precomputed` and preserve exact fallback behavior. This lowers filtering complexity from `O(R * T * (|O| + |S|))` to `O(|O| + |S| + R * T)`.
2. **Single-pass reference set for emulator unused-object detection (`DA-063`)**: Extract `collect_referenced_uids(dom_name, dom_files, all_domains_effective) -> set[str]` in `src/arodonata/testing/_emulator_lookup.py` scanning groups, Access/HTTPS/Threat/NAT rulebases, and gateway interfaces once per pass. `find_unused_objects` and each fixed-point iteration of `delete_unused_objects` perform `O(1)` set lookups against that set (`O(|E| + |R| + |G|)` per pass), while `collect_blocking_references` remains available for detailed single-entity delete error messages.
3. **Single canonical report object summary schema (`DA-047`)**: Create `src/arodonata/reports/_object_summary.py` owning the ordered canonical field specification (`ipv4-address`, `ipv6-address`, `subnet4`/`mask-length4`/`subnet-mask`, `subnet6`/`mask-length6`, IPv4/IPv6 ranges, `port`, `protocol`, `ip-protocol`, `icmp-type`, `icmp-code`, `fqdn`, `primary-category`, `urls-defined-as-regular-expression`, `url-list`, `members`, `description`, `comments`), shared plain formatting for `_collector_diffs.py` and `plan_report.py`, and shared `_SUMMARY_SPLIT_RE` + cell rendering hooks for `_renderer_formatting.py` so modified/planned objects never lose attributes.
4. **Generic typed sync & overlay engine (`DA-048`)**: Introduce `src/arodonata/core/services/_typed_cache_sync.py` defining a typed configuration/callback bundle for cache scope, type normalization, command resolution, incremental `show-changes` extraction, full reload, and `WriteSession` overlay application. `ObjectService` and `ServiceCacheService` delegate to this helper while preserving their distinct model types, `dns-domain` / `application-site` edge normalization, `@traced` spans, and logging channels.
5. **Acyclic `search/` package + VSX shared helpers (`DA-050`)**: Decompose `src/arodonata/core/services/search_service.py` into `src/arodonata/core/services/search/` (`terms.py`, `resolver.py`, `finder.py`, `query.py`, `service.py`, `__init__.py`), keeping `search_service.py` as a thin re-export shim and preserving `@traced` methods directly on `SearchService`. Consolidate VSX slot extraction and bidirectional parent-child linking helpers inside `src/arodonata/core/services/_asset_linking.py` (re-exported by `src/arodonata/core/services/asset_service.py`, keeping both modules well under 700 LOC).
6. **Canonical domain parser, MDS discovery/fallback, and `WriteSession` lifecycle (`DA-052`, `DA-049`)**: Move canonical domain dictionary parsing to `arodonata.core.models.domains.parse_domain_entry` (with optional `default_host` and deterministic `uid` fallback flags for `parse_domain_dict`), re-exporting it with preserved identity in `response_classifiers.py` and `sessions.py` (adapter layer) and wrapping/re-exporting `parse_domain_dict` in `domain_service.py` (core layer) alongside shared pagination/fallback helpers in `src/arodonata/core/services/_domain_discovery.py` without violating hexagonal import rules. Add `details-level="standard"` fallback preserving cached CMA IPs in `fetch_domain_topology_from_mds`, share the `WriteSession` publish/discard/logout context lifecycle via `open_api_write_session` in `core/context.py`, and decompose `ScriptRepositoryService.run_repository_script` and `_collect_gateway_routes_impl` into focused single-responsibility helpers.
7. **CPCRUD state-reader, staged runner, inverse, planner, and differ consolidation (`DA-051`, `DA-053`)**: Lift common cache-freshness, virtual-overlay, and single-item/list live-API lookups onto `_HybridStateReaderBase` (`_state_reader_common.py`) including the exact `item.name != name` guard now missing in `get_service_by_name`; extract `_run_on_adopted_staged_session` in `executor.py` with `asyncio.shield` on `logout_sid`; extract `_copy_prior_fields` in `inverse.py`; extract `_DomainPlanState` + single-pass step caching in `planner.py`; and split `compute_object_diff` / `compute_rule_diff` into type-specific helpers in `differ.py`.

## Risks / Trade-offs

- **Risk**: Moving `parse_domain_entry` or `open_api_write_session` might trigger hexagonal AST import violations or break `test_wave3_compat_and_fixes.py` function-identity assertions → **Mitigation**: Keep canonical pure domain model parsing in `core/models/domains.py` (only imports `core`), re-export the exact same function object through `response_classifiers.py` and `sessions.py`, and run `tests/unit/test_architecture_boundaries.py` and `tests/unit/test_wave3_compat_and_fixes.py` immediately per task.
- **Risk**: Decomposing `SearchService` could alter `@traced` span `__module__` / `__qualname__` if methods move out without binding or preserving `SearchService` wrappers → **Mitigation**: Keep public `@traced` methods defined on `SearchService` delegating to internal functions, and explicitly assert span metadata in tests.
- **Risk**: Consolidating object summary fields could change string formatting expected by existing report snapshot tests → **Mitigation**: Preserve exact `key=value` order and conditional field omission when values are unset (`None`), and verify `tests/unit/test_change_reports.py` and `tests/unit/test_reports_plan_report.py`.
